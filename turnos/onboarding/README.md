# Email de bienvenida

Usá `email-bienvenida.html` como cuerpo del correo para cada nuevo cliente.

1. Reemplazá `[Nombre]` por el nombre del profesional.
2. Adjuntá `tutorial.mov` al mensaje.
3. Enviá el correo desde `hola@induliru.com`.

El video queda en esta carpeta y no se publica en la página web.
